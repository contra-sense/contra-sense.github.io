    SYSTEM CONTRACT

    自主不等于失控

    把观察、认知、审批、执行和验证拆成不同能力，任何一层都不能自行扩大权限。

    01

    发现整台机器

    周期性识别同用户 Codex 进程，并把 observed 与 managed 明确分开。

    02

    只凭可追溯证据

    审查、习惯和知识节点都绑定不可变版本、来源与有界上下文。

    03

    变更必须确认

    建议可以自动生成，机器 mutation 必须穿过持久化 Approval Saga。

    04

    结果必须验证

    网关 ACK 不是成功，只有目标侧终态证据才能关闭执行闭环。

    A3S ORMSQLite / WAL

    为什么它不是“再包一层 SQL”

    审批与执行横跨多个持久边界，需要可取消事务、校验和迁移、比较并交换和精确租约。A3S ORM 在 adapter 内提供这些语义，不把数据库类型泄漏给 application。

    • 39 个有序、SHA 256 校验迁移
    • Tokio 安全的单连接执行器
    • 外键、WAL 与 bounded busy timeout
    • 安全重启所需的 durable projections
    阅读持久化设计
