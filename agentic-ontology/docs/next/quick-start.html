      #快速开始

      next 仍使用 Node.js 22、npm 11 和同一套静态构建入口：

      npm install
npm run build

      开发产品站使用 npm run dev，开发 3D Playground 使用 npm run dev:playground，开发版本文档使用 npm run dev:docs。

      新的语义构建器必须输出当前公开契约，并通过 npm run check:public 的隐私门禁后才能装配进 GitHub Pages。

      Rust CLI 的证据分批默认采用规范 Evidence ID 顺序；只有大语料需要词法加速时才显式增加 --evidence-index lexical。该参数只影响本体构建期分批，不会生成 Agent 检索接口。
