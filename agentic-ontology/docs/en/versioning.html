      #Versioning

      Documentation versions both product state and language. The default version and default language use paths without prefixes.

      ContentPath
      v0.1 Simplified Chinese/agentic-ontology/docs/
      v0.1 English/agentic-ontology/docs/en/
      next Simplified Chinese/agentic-ontology/docs/next/
      next English/agentic-ontology/docs/next/en/

      v0.1 records the current demo contract. next describes unreleased evolution. Every version must contain the same page set in Chinese and English; the build fails on translation-page drift.
