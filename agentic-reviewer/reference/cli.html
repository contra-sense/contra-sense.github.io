    #reviewerctl

    agentic-reviewer-cli 构建出的命令名是 reviewerctl。开发阶段可通过 Cargo 调用：

    cargo run -p agentic-reviewer-cli -- <command>

    #全局参数

    参数含义
    --socket <path>覆盖 daemon private socket，也可用 AGENTIC_REVIEWER_SOCKET
    --json输出 typed JSON，可放在 subcommand 前
    --help查看当前二进制的权威帮助

    #health

    cargo run -p agentic-reviewer-cli -- health

    检查 daemon 与数据库健康状态。

    #fleet

    cargo run -p agentic-reviewer-cli -- fleet list
cargo run -p agentic-reviewer-cli -- fleet refresh
cargo run -p agentic-reviewer-cli -- fleet status --instance os:...
cargo run -p agentic-reviewer-cli -- fleet status --pid 12345

    --instance 与 --pid 互斥。执行 mutation 时仍会使用完整 PID reuse safe identity，不会只信 PID。

    #codex

    cargo run -p agentic-reviewer-cli -- codex connections --limit 20
cargo run -p agentic-reviewer-cli -- codex endpoints
cargo run -p agentic-reviewer-cli -- codex launch --cd .
cargo run -p agentic-reviewer-cli -- codex launch --cd . "Review current changes"
cargo run -p agentic-reviewer-cli -- codex threads --connection codex-connection:... --limit 20
cargo run -p agentic-reviewer-cli -- codex turns --connection codex-connection:... --limit 20
cargo run -p agentic-reviewer-cli -- codex requests --connection codex-connection:... --limit 20

    launch 只接受 working directory 与可选 initial prompt，不透传任意 Codex options。

    #channel

    cargo run -p agentic-reviewer-cli -- channel list
cargo run -p agentic-reviewer-cli -- channel connect weixin --owner-name "Your name"
cargo run -p agentic-reviewer-cli -- channel connect telegram --owner-name "Your name"
cargo run -p agentic-reviewer-cli -- channel pairing read --pairing pairing:...
cargo run -p agentic-reviewer-cli -- channel pairing advance --pairing pairing:...
cargo run -p agentic-reviewer-cli -- channel pairing advance --pairing pairing:... --code 1234

    Telegram connect 要求 daemon 已通过 --telegram-bot-token-ref 或 AGENTIC_REVIEWER_TELEGRAM_BOT_TOKEN_REF 解析 channel Keychain 中的 BotFather token。CLI 只接收 channel ID 与 principal intent，不接收 secret。

    #approval

    cargo run -p agentic-reviewer-cli -- approval list --limit 20
cargo run -p agentic-reviewer-cli -- approval read AR-7F30AB19
cargo run -p agentic-reviewer-cli -- approval decide \
  AR-7F30AB19 \
  --principal principal:... \
  approve

    decision 只接受 approve 或 reject。

    #review

    cargo run -p agentic-reviewer-cli -- review list --limit 20
cargo run -p agentic-reviewer-cli -- review list --connection codex-connection:... --limit 20
cargo run -p agentic-reviewer-cli -- review acknowledge review-finding:... --principal principal:...
cargo run -p agentic-reviewer-cli -- review dismiss review-finding:... --principal principal:...
cargo run -p agentic-reviewer-cli -- review reopen review-finding:... --principal principal:...

    disposition 只改变用户处理状态，不删除 finding evidence 或 audit history。

    #habit

    cargo run -p agentic-reviewer-cli -- habit set \
  language:rust \
  testing.before-handoff \
  "Run workspace tests" \
  --principal principal:...

cargo run -p agentic-reviewer-cli -- habit list --status active
cargo run -p agentic-reviewer-cli -- habit list --scope project:... --limit 20
cargo run -p agentic-reviewer-cli -- habit read habit:...
cargo run -p agentic-reviewer-cli -- habit confirm habit:... --principal principal:...
cargo run -p agentic-reviewer-cli -- habit suspend habit:... --principal principal:...
cargo run -p agentic-reviewer-cli -- habit forget habit:... --principal principal:...

    scope 语法是 global、project:<project-id>、language:<label> 或 task:<label>。condition 必须是 bounded lowercase key。

    #knowledge

    cargo run -p agentic-reviewer-cli -- knowledge refresh .
cargo run -p agentic-reviewer-cli -- knowledge read --project project:...
cargo run -p agentic-reviewer-cli -- knowledge search \
  --project project:... \
  "approval orchestrator" \
  --limit 20
cargo run -p agentic-reviewer-cli -- knowledge materialize \
  --project project:... \
  --principal principal:... \
  --required-approvals 1 \
  --ttl-seconds 300

    materialize 只让 host 为当前 exact composed head 生成 immutable plan 并创建 Approval Saga。调用者不能提供 bytes、path、diff 或 target version，命令返回时不会直接写 project。若相同 content-addressed object 已存在则返回 already_materialized。

    #notification

    cargo run -p agentic-reviewer-cli -- notification subscriptions \
  --principal principal:... \
  --limit 20

    当前 CLI 只读取 explicit subscriptions。subscribe 与 unsubscribe 通过 verified IM exact commands 管理。

    #JSON 管道

    脚本应使用 --json，不要解析 human readable text：

    cargo run -p agentic-reviewer-cli -- --json approval list --limit 10

    RPC 返回 typed success 或 typed error。transport failure、domain rejection 与 not found 不应被脚本折叠成同一个字符串判断。
