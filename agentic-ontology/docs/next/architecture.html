      #架构

      next 在 v0.1 的边界上增加真实自动语义构建器，但不改变知识权威：

      公开文档白名单
  → 证据提取
  → Agent 语义提案
  → 确定性验证
  → KnowledgeRevision
  ├→ 人类审阅图谱
  └→ CognitivePackageDraft → A3S Use generation

      #Domain model

      Workspace、KnowledgeScope、Evidence、SemanticProposal、KnowledgeRevision 与 CognitivePackageDraft 的职责保持不变。A3S Use 继续拥有认知包的安装、锁定和发布状态。

      #Quality

      真实构建器需要增加确定性产物摘要、增量变化回执、引用覆盖评估和泄露回归测试。
