      #Playground

      Playground 展示 Agentic Ontology 的公开产品边界，而不是代码浏览器。构建器只读取白名单 v0.1 中英文文档，再生成闭合的公开语义投影。

      #三个联动区域

      #Agent 学习事件

      左侧账本记录 Agent 在什么时间读取了什么公开文档、理解了什么知识、建立了什么语义，以及变化进入哪个 Ontology Revision。选择事件会高亮图谱中的相关节点和关系。

      #语义 3D 本体图谱

      中间图谱按克制的结构灰阶呈现，支持搜索、类型筛选、相机聚焦、邻域高亮和重新取景。用户可以随时切换到键盘语义列表；无法使用 WebGL 时也会自动进入同一列表，并保留节点与关系导航。

      中间区域还可以切换到“构建链路”。该视图展示同一次公开构建的六个阶段：范围准入、公开证据、披露复核、公开投影、认知包交付和 Agent 评估。前四个阶段来自 disclosure presenter 的构建事实；A3S Use 尚未签发安装、锁定或发布回执，因此第五阶段保持等待，A3S Code 评估保持阻止。

      #认知包预览

      右侧展示从当前 KnowledgeRevision 计划生成的 schema-v3 认知包，包括 package 标识、OKF 与 Skill 表面，以及“草案 → A3S Use 安装/锁定/发布 → A3S Code Agent”的交付路径。当前状态明确为 preview、not-installed、not-locked 和 not-published。

      #交付边界

      公开投影保持以下最小契约：

      • 图谱只供人搜索、聚焦、审核和追溯；
      • Agent 不访问图谱，也没有公开图谱查询载荷；
      • 内部 Rust 图谱已绑定精确 KnowledgeRevision，但公开 Playground 不会直接读取该私有 JSON；
      • 认知包预览列出 schema-v3 knowledge profile、OKF 与 Skill 表面，但不推断任何生命周期成功；
      • A3S Code 只消费 A3S Use 已安装、锁定并发布的精确 generation。
      • 公开构建回执绑定完整产物；它证明 disclosure projection 的生成与边界，不代表认知包已经发布。
