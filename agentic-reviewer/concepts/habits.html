    习惯学习

    #学习你的做法，也允许你撤回它

    Reviewer 将 coding habit 表示为有作用域、有条件、有来源和可计数置信度的 durable claim。它不是一段无限增长的用户画像。

    #四种作用域

    Scope示例优先级
    Global所有项目交付前都给出验证结果低
    LanguageRust 修改运行 workspace tests中
    Task文档任务检查 broken links中
    Project当前 repository 使用特定门禁高

    Project scope 只由 host 根据 exact connection 与 thread cwd 解析。prompt 或 model 不能选择自己想读取的 Project habits。

    #显式偏好

    用户可直接创建 active habit：

    cargo run -p agentic-reviewer-cli -- habit set \
  language:rust \
  testing.before-handoff \
  "Run workspace tests" \
  --principal principal:...

    显式 correction 拥有独立 evidence source。它不会被普通聊天内容暗中创建。

    #推断 Candidate

    可选 Habit Learner 只读取 exact immutable Project revision 对应的 evidence，并输出 Candidate。Candidate 不会直接进入 active context，需要 exact 人类确认：

    cargo run -p agentic-reviewer-cli -- habit list --status candidate
cargo run -p agentic-reviewer-cli -- habit read habit:...
cargo run -p agentic-reviewer-cli -- habit confirm habit:... --principal principal:...

    确认操作引用 Candidate identity，不要求用户重新输入内容，因此可以证明批准的是哪一个 exact claim。

    #冲突、暂停与遗忘

    同一 slot 由 scope 与 condition 决定。出现冲突证据时，Reviewer 不会让两个相反 active claim 同时影响 review，而是暂停冲突并等待人类处理。

    cargo run -p agentic-reviewer-cli -- habit suspend habit:... --principal principal:...
cargo run -p agentic-reviewer-cli -- habit forget habit:... --principal principal:...

    suspend 保留 provenance 和 audit history。forget 删除 claim 及其 learning evidence，适合用户明确撤回这段长期记忆。

    #置信度不是模型自评分

    HabitConfidence 由 positive 与 negative evidence weight 计算 basis points。显式与推断 evidence 使用不同固定权重，model 不能自行声称“95% 可信”并覆盖 host policy。

    #给 Reviewer 分享偏好

    即使存在 active habits，它们也默认不会发送给远程 reviewer model。需要独立启用：

    AGENTIC_REVIEWER_LLM_PROJECT_HABITS=true

    启用后只发送 exact reviewed thread 对应 Project habits 加 Global habits。habit text 放在独立、escaped advisory section，不能当作 finding evidence，并与其他 context 共用字节上限。

    #可选 Habit Learner 配置

    AGENTIC_REVIEWER_ENABLE_HABIT_LEARNER=true \
AGENTIC_REVIEWER_HABIT_LEARNER_PROVIDER=openai \
AGENTIC_REVIEWER_HABIT_LEARNER_MODEL=your-model-id \
AGENTIC_REVIEWER_HABIT_LEARNER_API_KEY_REF=cognition:habit-learner-api-key \
cargo run -p agentic-reviewer-daemon

    Habit Learner 与 live Reviewer、Knowledge Curator 和 Control Agent 使用不同配置与 durable queue，避免一个开关隐式扩大其他 agent 的数据访问或权限。
