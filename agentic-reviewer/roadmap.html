    #当前 foundation 已经能做什么

    项目按安全关键 vertical slice 推进。状态来自当前代码、37 个 migrations 与 58 个已写 ADR，不使用“完成百分比”掩盖运行时边界。

    #已实现

    #本机与持久化基础

    • 同用户 Codex process observation 与 PID reuse safe identity
    • private local JSON RPC、daemon 与 reviewerctl
    • A3S ORM SQLite projections、journal、inbox、outbox 与 checksummed migrations
    • restart safe leases、typed retry、dead letter 与 recovery

    #Codex managed transport

    • 固定 codex-cli 0.147.0 的 Reviewer owned App Server
    • private WebSocket over Unix endpoint
    • explicit codex launch shared backend topology
    • bounded thread、turn 与 observed request projections
    • reconnect 后 loaded thread reconciliation

    #审批与执行

    • durable Approval Saga 与 canonical action digest
    • target version capture、revalidation、admission 与 per target serialization
    • one use attempt permit 与 no retry ambiguity handling
    • host owned terminal verification
    • 当前挂载 exact managed turn interrupt 与 observed Codex approval response 两类 mutation
    • verified IM lifecycle query 与 route bound notifications

    #Review 与 habit

    • deterministic failed turn findings
    • optional A3S Code structured finding candidates
    • evidence policy、Keychain provider config 与 durable review jobs
    • explicit habit claims、scope precedence、counted confidence、conflict suspension 与 physical forgetting
    • optional Candidate only Habit Learner 与 exact human confirmation
    • optional low authority Control Agent，所有 mutation proposal 仍进入 Approval Saga

    #项目知识

    • Rust symbol、Markdown section 与 bounded lat.md/ link scanner
    • content addressed immutable graph revisions
    • durable exact version refresh jobs 与 quiet successful turn hints
    • directed change neighborhoods 与 stale node repair proofs
    • verified manifests、incremental fragment reuse 与 global relinking
    • optional Candidate only Knowledge Curator
    • host validated semantic overlays
    • evidence preserving adjacent revision reconciliation
    • bounded composed read 与 search

    #IM

    • channel neutral account、binding、pairing、message 与 notification domain
    • OpenClaw Weixin compatible QR login、polling、getupdates 与 text sendmessage
    • exact status、Codex、finding、approval、habit 与 subscription commands
    • deterministic approval grammar 与 transactional delivery

    #下一阶段

    #Approval gated lat.md materialization

    内部图谱已经可用，但写入项目 lat.md/ 仍未挂载。后续实现必须：

    1. 对 exact graph revision 生成 deterministic diff。
    2. 绑定 current ProjectVersion 与 worktree digest。
    3. 进入普通 Approval Saga。
    4. dispatch 后验证 exact files 与 expected digest。
    5. 遇到 concurrent edit 时 stale，不覆盖用户修改。

    #不会为了路线图提前放宽的边界

    • 不用模型输出替代 human approval。
    • 不把 discovered process 自动提升为 managed。
    • 不把 gateway ACK 当作 mutation success。
    • 不让 connector 或 cognition 直接访问 SQLite。
    • 不为了自动更新知识而静默写脏 worktree。

    路线图中的每个 mutation 都必须先定义 exact target、digest、authority、ambiguity policy 与 verification proof，再进入 production composition。
