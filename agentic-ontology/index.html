    一个构建，两个出口

    图谱不是 Agent 的查询接口。

    每次构建产生同源但不同用途的产物：人通过 3D 图谱搜索、审核和追溯；Agent 只消费由 A3S Use 安装、锁定并发布的认知包 generation。

    01HUMAN REVIEW SURFACE自动构建的语义图谱

    让人看见每一次语义变化

    左侧事件账本记录 Agent 在什么时间读了什么文档、理解了什么知识、建立了什么语义。选择事件后，图中只强调这次变化。

    • 事件联动选择一次学习事件，只看这次修订影响的节点与关系。
    • 证据追溯从语义节点回到允许公开的文档，不展示源码位置。
    • 人工复核搜索、筛选、聚焦和检查出入关系都在浏览器内完成。

    02AGENT DELIVERY SURFACE由 A3S Use 发布认知包

    把通过审核的知识交给 Agent

    Agentic Ontology 只生成认知包草案。安装、依赖解析、generation 锁定和原子发布属于 A3S Use；Agent 宿主绑定精确 generation。

    • Agentic Ontology生成 KnowledgeRevision 和 schema-v3 package draft。
    • A3S Use解析依赖，安装、锁定并发布精确 generation。
    • A3S Code承载 Agent，并绑定 A3S Use 发布的 generation。
    OWNERSHIP / NO HIDDEN HANDOFFS

    A3S 组件分工

    职责按产物划分，不让图谱、包管理和 Agent 宿主互相越权。

    01

    Agentic Ontology

    生成证据、本体修订和认知包草案

    不安装认知包
    02

    A3S Use

    解析依赖、锁定并发布 Tool、MCP、OKF、Flow、Skill、UI 表面

    不生成或审核本体
    03

    A3S Code

    承载 Agent，消费 A3S Use 发布的精确 generation

    不直接读取 3D 图谱
    04

    A3S Flow

    保存探索、摄取、验证、编译和评估的工作流历史

    不拥有知识权威
    05

    A3S Cloud

    部署角色、节点、路由、Secret 与隔离 Runtime Task

    不拥有 Workspace 授权
    PUBLIC ARTIFACT
