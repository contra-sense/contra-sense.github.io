    AGENTIC ONTOLOGY · 架构预览

    把授权文档 编译成 Agent 的 认知包

    Agentic Ontology 读取允许进入范围的文档，建立带引用的本体，并生成 schema-v3 认知包草案。3D 图谱只供人审核；Agent 通过 A3S Use 使用已发布的 package generation。

    产品边界

    图谱给人看，认知包给 Agent 用

    两者来自同一份 KnowledgeRevision，但不是同一个接口。公开图谱负责观察、审核和追溯；认知包负责把 OKF 与 Skill 交给 Agent。

    人类界面

    3D 本体图谱

    查看文档、证据、概念、关系和每一次学习事件。可以搜索和聚焦，但不会作为 Agent 的运行时数据源。

    BUILD PATH / 01—04

    从文档到认知包

    当前仓库演示这条构建路径和公开数据边界，不宣称已经交付生产服务。

    1. 01

      读取授权文档

      KnowledgeScope 决定哪些资料版本可以进入构建。

    2. 02

      建立本体

      从证据提出概念和关系；未通过验证的提案不进入修订。

    3. 03

      生成认知包草案

      把 KnowledgeRevision 编译为 OKF 与 Skill 等认知表面。

    4. 04

      交给 A3S Use

      由 A3S Use 安装、锁定并原子发布精确 package generation。

    OWNERSHIP

    A3S 组件分工

    职责按产物划分，不让图谱、包管理和 Agent 宿主互相越权。

    01

    Agentic Ontology

    生成证据、本体修订和认知包草案

    不安装认知包
    02

    A3S Use

    解析依赖、锁定并发布 Tool、MCP、OKF、Flow、Skill、UI 表面

    不生成或审核本体
    03

    A3S Code

    承载 Agent，消费 A3S Use 发布的精确 generation

    不直接读取 3D 图谱
    04

    A3S Flow

    保存探索、摄取、验证、编译和评估的工作流历史

    不拥有知识权威
    05

    A3S Cloud

    部署角色、节点、路由、Secret 与隔离 Runtime Task

    不拥有 Workspace 授权
    PUBLIC ARTIFACT

    公开站点不发布源码

    生成器只读取白名单文档。构建门禁同时检查图谱 JSON 和最终静态站点。

    允许发布

    • 公开文档标题与链接
    • 概念、关系与语义状态
    • 学习事件与修订回执
    • 未发布的认知包协议预览
    BUILD GATE检查失败即停止

    禁止发布

    • 源码与代码片段
    • 仓库路径与行号
    • Git 历史与内部符号
    • Source Map 与本机路径
