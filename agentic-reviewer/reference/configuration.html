    #配置按能力分组，而不是共用一个万能开关

    reviewerd 使用 clap 参数，关键配置也支持环境变量。秘密只通过 Keychain reference 解析，不应出现在 shell history、SQLite 或日志里。

    #路径与 Codex

    环境变量CLI 参数含义
    AGENTIC_REVIEWER_SOCKET--socket私有 Reviewer Unix socket
    AGENTIC_REVIEWER_DATABASE--databaseSQLite 文件路径
    AGENTIC_REVIEWER_CODEX_BINARY--codex-binaryReviewer 自有 App Server 使用的 Codex executable
    AGENTIC_REVIEWER_CODEX_SOCKET--codex-socketmanaged Codex clients 使用的私有 endpoint
    AGENTIC_REVIEWER_DISABLE_MANAGED_CODEX--disable-managed-codex关闭自有 App Server，保留 durable queries
    AGENTIC_REVIEWER_KNOWLEDGE_QUIET_SECONDS--knowledge-quiet-period-secondsmanaged turn hint 后的合并静默期，默认 3 秒

    仅 CLI 参数提供的常用 interval：

    参数默认值
    --refresh-interval-seconds5
    --knowledge-refresh-interval-seconds30
    --approval-sweep-interval-seconds5
    --verification-reconciliation-interval-seconds2
    --notification-projection-interval-milliseconds250
    --codex-response-dispatch-interval-milliseconds250
    --codex-interrupt-dispatch-interval-milliseconds250
    --os-process-termination-dispatch-interval-milliseconds250
    --knowledge-materialization-dispatch-interval-milliseconds500

    #IM channels

    Weixin 不需要预配置 secret。Telegram adapter 始终注册，因此已有 account 可以从其随机 per-account Keychain reference 恢复；只有首次或新增 bot pairing 需要显式 bootstrap token：

    环境变量CLI 参数含义
    AGENTIC_REVIEWER_TELEGRAM_BOT_TOKEN_REF--telegram-bot-token-refchannel Keychain service 中的 BotFather token account name；值本身不是 token
    security add-generic-password \
  -U \
  -s dev.contra-sense.agentic-reviewer.channel \
  -a channel-bootstrap:telegram-bot \
  -w

AGENTIC_REVIEWER_TELEGRAM_BOT_TOKEN_REF=channel-bootstrap:telegram-bot \
cargo run -p agentic-reviewer-daemon

    显式配置了 reference 但 Keychain item 缺失、token 格式错误或 provider 拒绝 token 时，daemon 或 pairing 失败关闭。没有配置 reference 时，只禁止新 Telegram pairing，不影响 Weixin、本地查询或已持久化 Telegram account 的消息 worker。

    #Knowledge materialization

    环境变量CLI 参数含义
    AGENTIC_REVIEWER_KNOWLEDGE_MATERIALIZATION_REQUESTER_ID--knowledge-materialization-requester-id启用自动 proposal 时使用的现有 principal；未设置则禁用，绝不自动选择 Owner
    AGENTIC_REVIEWER_KNOWLEDGE_MATERIALIZATION_REQUIRED_APPROVALS--knowledge-materialization-required-approvals每个自动 proposal 的 quorum，默认 1
    AGENTIC_REVIEWER_KNOWLEDGE_MATERIALIZATION_TTL_SECONDS--knowledge-materialization-ttl-seconds自动 proposal TTL，默认 900 秒，最大 24 小时

    requester 必须在启动时已经存在、enabled 且能提出 mutation，否则 daemon 拒绝启动。这个开关只自动 reconcile approval proposal；不自动批准，也不绕过 Project actor、no-replace filesystem gateway 或 host verification。

    #Live Reviewer

    环境变量作用
    AGENTIC_REVIEWER_LLM_PROVIDERA3S Code provider
    AGENTIC_REVIEWER_LLM_MODELprovider model identifier
    AGENTIC_REVIEWER_LLM_API_KEY_REFcognition Keychain account name
    AGENTIC_REVIEWER_LLM_BASE_URL可选 OpenAI compatible endpoint
    AGENTIC_REVIEWER_LLM_EVIDENCEmetadata 或 redacted-error
    AGENTIC_REVIEWER_LLM_PROJECT_HABITS分享 scoped active habits
    AGENTIC_REVIEWER_LLM_PROJECT_KNOWLEDGE分享 bounded immutable graph summary
    AGENTIC_REVIEWER_LLM_PROJECT_TRANSITIONS分享 bounded directed transition metadata

    PROJECT_TRANSITIONS 要求同时开启 PROJECT_KNOWLEDGE，不满足时 daemon 拒绝启动。custom base URL 必须使用 HTTPS，只有 loopback server 可以使用 HTTP。

    #Evidence policy

    metadata 是默认值，不发送 raw error summary、command、diff、payload、token、item ID、resolution、worktree path 或 transcript。

    redacted-error 是显式 opt in，只允许有界并经过 credential、email 和 home path redaction 的 error summary。

    #Knowledge Curator

    环境变量作用
    AGENTIC_REVIEWER_ENABLE_KNOWLEDGE_CURATOR启用独立 Candidate only worker，默认 false
    AGENTIC_REVIEWER_KNOWLEDGE_CURATOR_PROVIDER独立 provider
    AGENTIC_REVIEWER_KNOWLEDGE_CURATOR_MODEL独立 model
    AGENTIC_REVIEWER_KNOWLEDGE_CURATOR_API_KEY_REF独立 Keychain reference
    AGENTIC_REVIEWER_KNOWLEDGE_CURATOR_BASE_URL独立 endpoint

    worker interval 使用 --knowledge-curator-worker-interval-seconds，默认 5 秒。

    #Habit Learner

    环境变量作用
    AGENTIC_REVIEWER_ENABLE_HABIT_LEARNER启用独立 Candidate only worker，默认 false
    AGENTIC_REVIEWER_HABIT_LEARNER_PROVIDER独立 provider
    AGENTIC_REVIEWER_HABIT_LEARNER_MODEL独立 model
    AGENTIC_REVIEWER_HABIT_LEARNER_API_KEY_REF独立 Keychain reference
    AGENTIC_REVIEWER_HABIT_LEARNER_BASE_URL独立 endpoint

    worker interval 使用 --habit-learner-worker-interval-seconds，默认 5 秒。

    #Control Agent

    环境变量作用
    AGENTIC_REVIEWER_ENABLE_CONTROL_AGENT允许 bounded raw IM text egress，默认 false
    AGENTIC_REVIEWER_CONTROL_AGENT_PROVIDER独立 provider
    AGENTIC_REVIEWER_CONTROL_AGENT_MODEL独立 model
    AGENTIC_REVIEWER_CONTROL_AGENT_API_KEY_REF独立 Keychain reference
    AGENTIC_REVIEWER_CONTROL_AGENT_BASE_URL独立 endpoint

    Control Agent 没有 worker interval，因为每次 inbox drain 最多接纳一个 provider call，deterministic commands 总是先执行。

    #Keychain 写入

    不同 cognition role 使用独立 account name。下面示例不会把 value 放进参数或 shell history：

    security add-generic-password \
  -U \
  -s dev.contra-sense.agentic-reviewer.cognition \
  -a cognition:reviewer-api-key \
  -w

    -s 是固定 service，-a 对应配置中的 *_API_KEY_REF。cognition 使用 dev.contra-sense.agentic-reviewer.cognition，channel credential 使用 dev.contra-sense.agentic-reviewer.channel，两个权限面不复用 item。provider 配置缺失或 Keychain lookup 失败时，可选 cognition 会 degraded，核心确定性查询与 finding 仍继续服务。

    #日志

    daemon 使用 RUST_LOG 控制 tracing filter。默认 filter 是 reviewerd=info：

    RUST_LOG=reviewerd=debug cargo run -p agentic-reviewer-daemon

    不要在生产日志中开启依赖级别的无界 trace。数据库中只存固定失败 reason code，不存 adapter error text。
